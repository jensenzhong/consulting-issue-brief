# 顾问问题清单

**✨ 被领导疯狂夸夸的「问题整理 Skill」——把零散材料变成清晰、可研判的问题清单。**

将企业访谈转写、周报、异常台账等材料整理为供外部顾问研判的问题清单。重点是还原实际业务场景、交接、已有数据和已发生的影响，让顾问据此提出建议；清单本身不提供解决方案。

## 适用范围

适合以制造业运营和跨部门协作为背景、需要形成 Word 问题清单的任务。默认结构包括现行流程地图、数据判断前提、协调问题、现场异常和会议勾选目录；每个问题按五个字段描述。其他行业或已有不同交付要求时，应先调整结构和版式。

## 安装与使用

将本仓库下载或克隆为名为 `consulting-issue-brief` 的目录，并按所用 AI 工具的说明将该目录加入其 skills 目录。目录中必须保留 `SKILL.md` 和 `references/`。不同工具对安装位置、自动发现和调用方式的支持可能不同，请以该工具的文档为准。

在支持此 skill 格式的工具中，提供有权使用的材料，并说明期望的读者、范围和输出格式。例如：

> 请根据提供的访谈转写和周报，整理一份供外部顾问研判的问题清单。只描述问题、现场和已发生的影响；数据口径不一致时请说明。

工具支持显式调用时，也可按其语法指定 `consulting-issue-brief`。生成结果应由熟悉业务和数据的人员复核。

## 发布与隐私

不要将客户访谈、录音、周报、台账、成稿、企业标识或其他未获授权的材料提交到公开仓库。`.gitignore` 只能减少误提交，不能识别所有敏感信息；提交前仍需检查文件内容、暂存区和 Git 历史。示例应使用虚构数据。
