# 竖向现状流程图（可选模板）

当材料能支持流程梳理、且图有助于读者理解问题时使用。环节、顺序、参与者、交接和卡点都从本次材料提取，不套用占位步骤或其他企业的流程。把无法确认的环节标为待核实；只有材料明确表明现状缺失时才使用缺失样式。不同链路不适合合并时分图或画分支。

图和相关对照表采用相同的环节名称与顺序。每框写一个可识别的阶段，简述谁在做、交给谁和实际状态；用短标签对应问题条目。跨多个环节的共同机制可以写在图脚。图展示现状，不把假设的理想流程画成现状。

## 可选视觉与出图方法

参考 [flowchart-skeleton.png](flowchart-skeleton.png) 的竖向布局：正常环节为深蓝，缺失环节为橙色；页面和字体应符合用户指定的模板，并保证打印时清晰。模板图只有占位文字，不要直接放入成稿。

如使用附带的 Python 脚本，需安装 Pillow，并确保系统中有授权的楷体和 Times New Roman。复制 [steps-template.json](steps-template.json)，按材料填写 `title`、`subtitle`、`footer` 和各 `steps` 的 `num`、`title`、`who`、`tags`；明确缺失的环节可设 `missing: true`。然后运行：

```bash
python references/make_flow_chart.py your-steps.json -o flowchart.png
```

脚本适合简短的线性流程，最多九个环节；复杂分支或文本过长时应分图或选用其他工具。出图后人工检查文字、箭头和标签是否完整清楚，并核对来源、顺序、缺失标记和占位内容。将图放在合适位置，勿硬挤到一页。
